# DADSスライド作成スキル

デジタル庁デザインシステム（DADS）は行政Webサイト向けのルールだが、
「誰も取りこぼさない」という目的はスライドにもそのまま当てはまる。
スライドはプロジェクターの薄い色・後方席・白黒印刷など、Webより悪い条件で読まれるためである。

このスキルでは、スライドを **横1280px × 縦720px の画面** とみなし、DADSのWeb向け数値をそのまま当てはめる。

## 作業の流れ

1. **内容を固める**：依頼から「誰に・何を決めてほしいか」と各スライドの主張（1スライド1メッセージ）を書き出す。
2. **型を選ぶ**：各スライドの中身の形に合う型を `references/layouts.md` から選ぶ。
   - 比較するデータ → 表（カードは使わない）
   - 並べる対象物（プラン・商品・人）→ カード
   - 結論と根拠 → 上に結論・下に根拠の縦の流れ
3. **生成する**：`scripts/dads_pptx.py` の部品関数で組み立てる。数値は `references/tokens.md` のトークンだけを使う。使い方の例は `scripts/build_sample.py`。
   ```bash
   python3 .claude/skills/dads-slides/scripts/build_sample.py out.pptx
   ```
4. **検査する**：
   ```bash
   python3 .claude/skills/dads-slides/scripts/check_deck.py out.pptx
   ```
   文字サイズ・コントラスト・8px グリッド・14px 使用箇所を機械チェックする。違反があれば直して再実行。
5. **目で確認する**：`soffice --headless --convert-to pdf out.pptx` でPDF化し、画像で見て、はみ出し・重なりがないか確かめる。

## 守る5つのルール（詳細と数値は references/tokens.md）

### 1. 文字
- 本文 16px、見出し 18〜22px、スライドタイトル 32px。
- 14px は出典・注記だけ。それ以外で 14px 以下は使わない。
- 行間は文字サイズの 1.5 倍以上。書体は Noto Sans JP（なければ游ゴシック/メイリオ）。

### 2. 色
- 文字と背景のコントラストは 4.5:1 以上、線・図形は 3:1 以上。
- 主色は青の1色だけ。強調色を増やさない。
- **色だけで情報を区別しない。**「推奨」「完了」「悪化」などは必ず文字ラベルを添える。増減は「＋8%」「−2pt」と文字で書く。悪化だけ赤いラベルにする。
- 白黒で印刷しても意味が伝わるかを常に確認する。

### 3. 余白
- すべての位置・サイズを 8px の倍数で決める。
- 左右の余白 64px、列の間 32px（本文 16px の 2 倍以上）。

### 4. 区切り
- 区切りは「余白」が主役、灰色の線と見出しが補助。
- 飾りの枠・影・グラデーションは使わない。
- 枠で囲むのは補足情報だけ。カードには必ず輪郭線を付け、影は付けない。

### 5. 表
- 見出し行は太字にし、黒い線でデータと区切る。
- セルは上寄せ、数値は右寄せ。
- 推奨の列・行だけ薄い青で塗り、見出しに「推奨」ラベルを付ける。

## よくある作り直し（色の差し替えだけでは足りない）

| 元の構図 | DADSに沿った構図 | 理由 |
|---|---|---|
| シナリオを3枚のカードで横並び | 「シナリオ×観点」の表 | 比較するならカードより表。横に目を動かすだけで比べられる |
| 推奨列を色で塗るだけ | 色＋「推奨」ラベル＋太字見出し＋黒線 | 色だけで区別しない |
| 結論と根拠を左右に分割、枠で囲む | 上に結論・下に根拠3つ、線と余白で区切る | 読む順序が一本になる。枠は飾りなので外す |
| KPIの増減を緑/赤の矢印だけで表示 | 「＋8%」「−2pt」の文字、悪化だけ赤ラベル | 白黒でも読める |
| リンクを色だけで表示 | 青文字＋下線 | DADSのリンク表現 |

## やってはいけないこと
- 主色以外のアクセント色を足す（赤は「悪化・エラー」ラベル専用）
- 影・グラデーション・角丸の強いボックス・アイコンだけの説明
- 14px 以下の本文、行間 1.5 倍未満
- 中央揃えの長文（タイトル以外は左揃え）
- 1 スライドに主張を 2 つ以上入れる
