# 型の一覧

中身の「形」で型を選ぶ。迷ったら「比較 → 表」「対象物の並び → カード」「主張と理由 → 縦の流れ」。
各型の `dads_pptx.py` 関数名を併記する。

## 資料の骨格

| 型 | 構図 | 関数 |
|---|---|---|
| 表紙 | 左寄せタイトル32px＋サブタイトル＋日付・作成者。飾りなし、下に1本の区切り線 | `title_slide` |
| 索引（目次） | 型名・章名を青文字＋下線のリンクで並べ、各スライドへ飛ぶ | `index_slide` |
| エグゼクティブサマリ | 左に要点4つ（番号付き）、右に主要数値3つ。数値だけ大きく、間は線で区切る | `exec_summary_slide` |
| 結論＋3つの根拠 | 上に結論（22px太字）、区切り線、下に根拠3列（見出し18px＋本文16px） | `conclusion_reasons_slide` |
| セクション扉 | 章番号＋章名のみ。主色は番号だけ | `section_slide` |

## 数値・データ

| 型 | 構図 | 関数 |
|---|---|---|
| KPIダッシュボード | 上段にKPIタイル（数値＋「＋8%」等の増減文字）。悪化だけ赤ラベル「悪化」 | `kpi_slide` |
| シナリオ比較 | 「シナリオ×観点」の表。数値右寄せ。基準シナリオの列に「基準」ラベル | `table_slide` |
| 選択肢比較表 | 選択肢×評価観点の表。推奨の列を薄青＋見出しに「推奨」ラベル | `table_slide(highlight_col=)` |
| グラフ＋示唆 | 左にグラフ（主色1色＋灰色）、右に示唆を3行。凡例ではなく直接ラベル | python-pptx の chart を使い、色は primary と line のみ |

## 対象物の並び

| 型 | 構図 | 関数 |
|---|---|---|
| プラン比較カード | カード3枚（輪郭線あり・影なし）。推奨カードだけ薄青面＋「推奨」ラベル | `cards_slide` |
| 人物・体制 | カードに氏名・役割・担当。写真は任意 | `cards_slide` |

## 流れ・時間・構造

| 型 | 構図 | 関数 |
|---|---|---|
| 手順・ステップ | 番号付きの横並び（最大5）。矢印は細い灰色線 | `steps_slide` |
| システム構成・データフロー | 入力／処理／出力の3列。中心の処理基盤だけ薄青面 | `flow3_slide` |
| KPIドライバーツリー | 最終目標→指標→施策。重点の指標・施策だけ薄青＋「重点」ラベル | `tree_slide` |
| ロードマップ | 横軸に期間、行に施策の表形式。現在地は文字で「現在」と示す | `table_slide` で代替 |

## 構図を変えるべき合図

- 同じ項目名が複数のカードに繰り返し出てくる → 表にする
- 色の違いを説明しないと意味が分からない → 文字ラベルを足す
- 枠が3つ以上入れ子・並列になっている → 枠を外し、線と余白にする
- 左右に分けたが読む順序が決まっている → 上下の流れにする
